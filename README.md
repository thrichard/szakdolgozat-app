# 🎓 Oktatási Portál - Szakdolgozat

Ez a projekt egy modern, MERN stack (MongoDB, Express, React, Node.js) alapú webalkalmazás, amely digitális oktatási platformként szolgál tanárok és diákok számára.

## 🚀 Alkalmazott Technológiák
- **Frontend:** React.js, Vite, Tailwind CSS, React Router DOM
- **Backend:** Node.js, Express.js
- **Adatbázis:** MongoDB (Mongoose ODM)
- **Hitelesítés:** JSON Web Token (JWT) és Bcrypt jelszótitkosítás

## ✨ Főbb Funkciók

### Tanári jogosultság (Teacher)
- Tananyagok feltöltése és menedzselése (cím, leírás, kategória, külső hivatkozások).
- Interaktív kvízek és vizsgafeladatok létrehozása.
- Diákok eredményeinek valós idejű nyomon követése az "Osztálynaplóban".

### Diák jogosultság (Student)
- Biztonságos bejelentkezés a portálra.
- Elérhető tananyagok böngészése és megtekintése.
- Kvízek kitöltése lépésről-lépésre haladó űrlap segítségével.
- Saját statisztikák és korábbi vizsgaeredmények megtekintése.
